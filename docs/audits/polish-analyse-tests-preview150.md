# Preview150 — analyse des dix tests en échec

Référence : suite complète exécutée sur `d6d9321` (Preview150), 10 échecs. Tous les tests sont conservés ; certains titres sont actualisés pour ne plus décrire l'ancien design. Les nouvelles assertions vérifient les ressources réellement utilisées et leurs valeurs, sans abaisser les seuils de contraste ou de dimension. Ce sont des contrôles structurels : ils ne remplacent pas une inspection visuelle sur téléphone et tablette.

## Portée et limites

- Les contrôles ajoutés vérifient aussi les marges de réglages symétriques 20 dp dans la fabrique native partagée et le titre sur deux lignes avec redimensionnement dans les quatre layouts. Ils ne prouvent pas l'absence de troncature pour tous les textes et tailles de police : `ellipsize=end` reste présent.
- Les corrections de couleur des actions ne modifient ni leurs gestionnaires, ni la session, ni les requêtes. La démo reste isolée et fictive.
- Le blur-behind, les pistes dégradées des interrupteurs, le chevauchement historique de 14 px et les erreurs JS restent non résolus ou non validés, comme indiqué dans le tableau de la Preview150.
- Aucune nouvelle preview n'a été construite ou livrée avec ces corrections ; les captures Preview150 ne les montrent donc pas.
