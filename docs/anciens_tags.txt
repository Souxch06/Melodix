# Tags de preview supprimes

Le 2026-10-31, toutes les releases de preview anterieures a
`v1.2.2-test.83-preview` ont ete supprimees, puis leurs tags orphelins, pour ne
conserver qu'une seule version telechargeable.

- Aucune release n'a jamais ete utilisee par le pipeline : le `versionCode`
  vaut `version + test_number + 28 + numero_de_run`, il ne depend donc pas de
  l'existence des tags. Supprimer ces tags ne casse aucune mise a jour future.
- Les commits sont **intacts** : seul le nom qui les designait a disparu.

## Restaurer un tag

```bash
git tag <nom> <sha> && git push origin <nom>
# ou, si l'on veut la release complete : relancer le workflow en mode
# workflow_dispatch avec release_tag=<nom> et source_ref=<sha de 40 caracteres>
```
