# Aperçus de l’interface mobile Melodix

Ces PNG sont des **maquettes visuelles** de l’accueil mobile et de la bibliothèque, avec des titres et pochettes fictifs. Ils illustrent le dock inférieur, les zones tactiles élargies et le mini-lecteur compact ajoutés aux styles du WebView.

Ce ne sont pas des captures d’écran d’une APK exécutée : aucune APK n’a été reconstruite et aucun appareil/émulateur n’a été testé pour cette modification.
