# Aperçus de l’interface mobile Melodix

Ces PNG sont des **maquettes visuelles** de l’accueil mobile et de la bibliothèque, avec des titres et pochettes fictifs. Ils illustrent le dock inférieur, les zones tactiles élargies, l’ouverture de la bibliothèque et le mini-lecteur compact.

Dans l’application, les cartes, titres et pochettes restent ceux du compte Spotify : les exemples de ces maquettes ne sont pas injectés. Le code applique le cadre mobile à la page Spotify existante.

Ce ne sont pas des captures d’écran d’une APK exécutée : aucune APK n’a été reconstruite et aucun appareil/émulateur n’a été testé pour cette modification.
